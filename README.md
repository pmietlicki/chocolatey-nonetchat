# Chocolatey package for NoNetChat

Source of the [`nonetchat`](https://community.chocolatey.org/packages/nonetchat) Chocolatey package.

```powershell
choco install nonetchat
```

The package downloads the official portable Windows x64 build from the
[nonetchat-windows releases](https://github.com/pmietlicki/nonetchat-windows/releases)
(the same file as on [nonetchat.com](https://nonetchat.com)), verifies its SHA-256 and
adds a Start Menu shortcut. Uninstalling keeps your profile and history.

Packaging scripts: Apache-2.0. NoNetChat itself: see the
[terms of use](https://nonetchat.com/en/terms/).
